# Tonari

[English](README.md)

Tonari は、現代の macOS と Linux（WSL2 を含む）で、普段使う Bash を置き換えるための Rust 製シェルです。ツールは既存の Bash 向け連携を使え、端末を開いた人はプラグインの導入や設定をせずに初回から履歴候補・補完・複数行編集を使えることを目指します。起動が速いこと、コマンドの実行が速いこと、実行ファイルが小さいことを設計の要件にしています。

**現在は最初の試作段階です。** フォアグラウンドのコマンドとパイプラインを端末で試せます。ログインシェルとしての利用、Bash の起動設定の読み込み、外部ツールとの連携は今後実装します。

## 試す

Rust 1.87 以降でビルドできます。この例ではビルドするマシンの CPU 向けに最適化します。

```sh
RUSTFLAGS='-C target-cpu=native' cargo build --release --locked
./target/release/tonari -c "printf '%s\n' one two three | wc -l"
./target/release/tonari
```

ビルド後の最初のコマンドは `3` を表示します。`tonari$ ` プロンプトでは `ls -1 | wc -l > count`、続けて `cat count` を試せます。作業ディレクトリに `count` というファイルを書き込みます。Ctrl-C で実行中のパイプラインを中断すると、プロンプトに戻ります。`exit` または空のプロンプトで Ctrl-D を押すと終了します。

## いま使える機能

- 対話入力と `-c` は共通のパーサー・実行系を使います。UTF-8 のコマンド入力、リテラルの引数、単一引用符・二重引用符、バックスラッシュによるエスケープ、コメント、セミコロン・改行によるコマンドの区切りに対応します。
- 外部コマンドは `PATH` または指定されたパスから起動します。パイプの各段は並行して動きます。パイプやファイルには任意のバイト列を流せます。
- ファイルへのリダイレクトは `<`、`>`、`>>` に対応します。標準のファイル記述子 0・1・2 の複製とクローズもできます。パイプを接続した後、各コマンドのリダイレクトを左から順に適用します。
- パイプラインは最後の段の終了ステータスを返します。組み込みコマンドは `:` と `exit` です。`-c` の末尾が単独の外部コマンドなら、Tonari のプロセスをそのコマンドに直接置き換えられます。
- 対話入力には端末標準の行入力を使います。引用符や末尾のパイプで行が続くときは、次の行を入力できます。

変数と展開、シェル関数、`cd`、`source`、`&&` と `||`、ファイルや標準入力からのスクリプト実行、バックグラウンドジョブ、一時停止と再開、履歴、補完は今後の実装対象です。ログインモードと Bash 名での起動口も今後追加します。

## 互換性と性能の目標

開発時の比較基準は Debian 13 の GNU Bash 5.2.37 と Ubuntu 26.04 の GNU Bash 5.3.9 です。両者に共通する Bash の構文、起動ファイルの規則、シェル変数、外から観察できるプロセスの挙動を互換対象とします。インタプリタとプロセス制御は Tonari 自身が実装します。

配布時には、ツールが直接起動できる `libexec/tonari/bash` を実体とし、利用者向けの `tonari` はその実行ファイルへのリンクにする予定です。別のシェルから起動した Tonari は `SHELL` を継承し、専用の Bash パスをログインシェルに選んだ場合は、ツールも `SHELL` 経由でそのパスを選べる設計です。実際のツールとの結合テストはこれからです。

速さと小ささの比較対象は GNU Bash と brush です。Debian arm64 での最初の計測では、キャッシュが温まった状態でプロンプトが表示されるまでの中央値は **Tonari 0.90 ms、Bash 1.15 ms、brush 1.76 ms** でした。Tonari のリリース実行ファイルは **397,968 バイト**です。組み込みコマンドが二つ、プロンプトが最小構成の時点での基準値です。[全計測値・p95・計測条件](docs/benchmarks.md)

## 開発

```sh
cargo test --locked
cargo build --locked
python3 tests/shell.py target/debug/tonari
python3 tools/bench.py target/release/tonari --bash /bin/bash
```

結合テストでは、出力・ファイルの内容・終了ステータスを Bash と比較し、疑似端末で Ctrl-C の動作を確認します。`REFERENCE_BASH` で比較用の Bash を指定できます。ベンチマークに brush を加えるには `--brush /path/to/brush` を渡してください。
